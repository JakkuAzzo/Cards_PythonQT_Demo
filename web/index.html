The app is where play happens.

This page is deliberately simple: it explains Cards, points to builds, and records what is moving forward. Games, nearby connections, and AR stay in the native apps.

01

Private cards, shared state

Move between a shared Table, private Your deck, and Combined view. Board games can turn the table into a score tracker or leaderboard.

02

Templates, not a store

Start with the original Classic Pack, Poker, Guess Who, or a prompt deck. Lightweight templates select safe resources and sensible multiplayer defaults.

03

Nearby by design

Use a conventional screen anywhere; open AR only when a surface adds something. Local connections are designed to work without cloud accounts.

Preview builds

Android APK, macOS DMG, and Windows executable builds are published as GitHub prereleases. They are for testing and are not yet code-signed or notarized. iOS distribution follows when an Apple Developer account is connected.
