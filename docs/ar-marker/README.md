# Cards table marker v1

Print `cards-table-marker-v1.svg` at **100% scale** on a flat, matte surface. The black square must measure exactly **160 mm × 160 mm** from edge to edge. Do not crop it, laminate it with a reflective finish, or show it only on another phone screen.

The marker is a shared physical reference, not a networking identifier. Each phone recognises and anchors to it locally; nearby messages communicate only that the marker is ready/lost and the game revision. This prevents mixing incompatible AR world coordinates across iOS and Android.
